# site

Personal portfolio and minimalist profile website.

## Development & Tailwind CSS

Tailwind CSS v4 is configured via `@tailwindcss/cli`.

- **Watch styles during development**:
  ```bash
  npm run dev
  ```
- **Build production minified CSS**:
  ```bash
  npm run build:css
  ```

Source CSS is located at [`css/input.css`](css/input.css) and compiles to [`css/style.css`](css/style.css).
